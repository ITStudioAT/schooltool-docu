Erste Schritte mit Schooltool.

In dieser Anleitung richtest du Schooltool lokal ein, lernst die Projektstruktur kennen und deployst deine erste eigene App-Instanz — egal ob Anmelde-, Nachhilfe- oder Neuigkeitentool.

Zuletzt aktualisiert 24. April 2026 Version v2026.04 Autor:in G. Kron

Voraussetzungen

Bevor du loslegst, stelle sicher, dass folgende Werkzeuge auf deinem System installiert sind. Schooltool basiert auf Node und Docusaurus — beides läuft problemlos auf macOS, Linux und Windows (WSL).

  • Node.js ≥ 20.0 — empfohlen via nvm
  • Git ≥ 2.40
  • Eine moderne IDE — wir empfehlen VS Code
Hinweis für Schulnetzwerke Wenn du hinter einem Proxy arbeitest, setze die Umgebungsvariablen HTTPS_PROXY und NO_PROXY, bevor du die Installation startest.

Installation

Klone das Repository und installiere die Abhängigkeiten. Schooltool benutzt einen Monorepo-Aufbau — jede App lebt in apps/, gemeinsame Komponenten in packages/.

npm pnpm yarn 
# Repository klonen
git clone https://github.com/itstudio/schooltool.git
cd schooltool

# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev // → http://localhost:3000

Die ersten drei Schritte

Schule konfigurieren

Trage Name, Kürzel und Logo deiner Schule in config/school.ts ein. Das Tool passt sich automatisch an.

Erste Admin-Person anlegen

Über npm run seed:admin wird ein initialer Account angelegt. Passwort wird im Terminal ausgegeben — sofort ändern.

App auswählen & ausrollen

Aktiviere die gewünschte App im Dashboard (z. B. Nachhilfetool) und teile den Link mit der Schulgemeinschaft.

Nächste Schritte

Du bist startklar. Tauche jetzt tiefer in die einzelnen Apps ein, oder lies die Architektur-Übersicht, um zu verstehen, wie Schooltool aufgebaut ist.
