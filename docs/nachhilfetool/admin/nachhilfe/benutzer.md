# Benutzer

Unter dem Menüpunkt _Benutzer_ können Schüler:innen, die beim Nachhilfetool angemeldet sind, verwaltet werden.

<img
src={require('./\_img/benutzer.png').default}
alt="Benutzer"
className="image-800"
/>

## Benutzer hinzufügen

Normalerweise melden sich Schüler:innen selbständig beim Nachhilfetool an.

Es ist aber auch möglich, dass ein:e Nachhilfetool-Administrator:in eine:n neue:n Schüler:in hinzufügt.

Klicken Sie dazu auf _Hinzufügen_.

<img
src={require('./\_img/benutzer_hinzufuegen_button.png').default}
alt="Benutzer hinzufügen"
/>

Jetzt können folgende Datenfelder ausgefüllt werden:

- Nachname
- Vorname
- E-Mail
- Schulklasse
- Geschlecht

<img
src={require('./\_img/benutzer_hinzufuegen.png').default}
alt="Benutzer hinzufügen"
className="image-800"
/>

## Weitere Aktionen

Außerdem sind folgende weitere Aktionen für Benutzer möglich:

- Ändern
- Sperren / Entsperren
- Bestätigen
- Löschen

<img
src={require('./\_img/benutzer_weitere_aktionen.png').default}
alt="Benutzer weitere Aktionen"
className="image-800"
/>

### Ändern

<img
src={require('./\_img/benutzer_aendern.png').default}
alt="Benutzer ändern"
/>

Mit diesem Menüpunkt können die bestehenden Benutzerdaten geändert werden.

### Sperren / Entsperren

<img
src={require('./\_img/benutzer_sperren.png').default}
alt="Benutzer sperren"
/>

Mit diesem Menüpunkt kann ein:e Schüler:in gesperrt werden.<br />
Danach kann sich die Schüler:in nicht mehr am System anmelden.

✉️ Die Schüler:in wird über diesen Vorgang per E-Mail verständigt.

<img
src={require('./\_img/benutzer_entsperren.png').default}
alt="Benutzer entsperren"
/>

Mit diesem Menüpunkt kann ein:e gesperrte:r Schüler:in wieder entsperrt werden.<br />
Danach kann sich die Schüler:in wieder normal am System anmelden.

✉️ Die Schüler:in wird über diesen Vorgang per E-Mail verständigt.

### Bestätigen

<img
src={require('./\_img/benutzer_bestaetigen.png').default}
alt="Benutzer bestätigen"
/>

Mit diesem Menüpunkt kann eine neu registrierte Schüler:in, die auf die Freigabe wartet, freigeschaltet werden.<br />
Danach kann sich die Schüler:in am System anmelden.

### Löschen

<img
src={require('./\_img/benutzer_loeschen_1.png').default}
alt="Benutzer löschen 1"
/>

Mit diesem Menüpunkt kann ein:e Schüler:in gelöscht werden.

Das Löschen muss noch einmal bestätigt werden.

<img
src={require('./\_img/benutzer_loeschen_2.png').default}
alt="Benutzer löschen 2"
className="image-800"
/>
