# Profil

Unter dem Menüpunkt _Profil_ können Sie folgende Einstellungen vornehmen:

- Benutzerprofil ändern
- Kennwort ändern
- 2-Faktoren-Authentifizierung aktivieren/deaktivieren

<img
src={require('./\_img/profil.png').default}
alt="Profil"
className="small-image"
/>

## Benutzerprofil ändern

Hier können Sie Ihren Namen oder Ihre E-Mail-Adresse ändern.

## Kennwort ändern

Hier können Sie ein neues Kennwort vergeben.

Geben Sie dazu Ihr neues Kennwort (mind. acht Zeichen) zweimal ein und klicken anschließend auf **Weiter**.

<img
src={require('./\_img/profil_kennwort_aendern_1.png').default}
alt="Kennwort ändern"
className="small-image"
/>

Sie erhalten nun auf Ihre E-Mail-Adresse einen 6-stelligen Code.<br />
Geben Sie diesen Code hier ein:

<img
src={require('./\_img/profil_kennwort_aendern_2.png').default}
alt="Kennwort ändern - Code eingeben"
className="small-image"
/>

Wenn Sie den Code korrekt eingegeben haben und auf **Weiter** klicken, ist Ihr Kennwort geändert.

## 2-Faktoren-Authentifizierung

Die 2-Faktoren-Authentifizierung sichert Ihren Zugang zum System doppelt ab.<br />
Sie erhalten beim Einloggen an eine weitere E-Mail-Adresse einen Code, den Sie eingeben müssen.<br />
Erst nach Eingabe des korrekten Codes werden Sie am System angemeldet.

:::info
Ihre E-Mail-Adresse und die E-Mail-Adresse für die 2-Faktoren-Authentifizierung müssen sich unterscheiden.
:::

:::tip
Die 2-Faktoren-Authentifizierung erhöht die Sicherheit Ihres Zugangs wesentlich.
:::

Sie können die 2-Faktoren-Authentifizierung jederzeit wieder deaktivieren.
