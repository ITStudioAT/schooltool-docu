# Einstieg

Rufen Sie folgende Seite auf:

```
schooltool.at/admin
```

## Das erste Anmelden

Wenn Sie noch nie am System als Lehrer:in angemeldet waren, geben Sie Ihre E-Mail-Adresse ein und klicken Sie beim Anmeldevorgang auf **Neuer Lehrer**.

<img
src={require('./\_img/login_neuer_lehrer.png').default}
alt="alt text"
className="small-image"
/>

Sie erhalten auf Ihre E-Mail-Adresse einen 6-stelligen Code.<br />
Geben Sie diesen Code ein und klicken auf **Anmelden**.

:::tip
Gehen Sie gleich nach der Anmeldung zu Ihrem Profil und vergeben ein Kennwort.
:::

## Anmelden

Geben Sie Ihre E-Mail ein und klicken auf _Weiter_.<br />
Geben Sie danach Ihr Kennwort ein und klicken auf _Anmelden_.
