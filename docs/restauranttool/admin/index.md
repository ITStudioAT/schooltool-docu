# Admin

Hier finden Sie die Beschreibung aller Möglichkeiten für Administratoren des Restauranttools.

## Bereiche

| Bereich | Beschreibung |
| --- | --- |
| [Anmeldung](./anmeldung) | Einstieg in den Admin-Bereich. |
| [Einstellungen](./einstellungen/) | Grundlegende Restaurant-Einstellungen wie Kategorien, freie Tage, Speisezeiten, Benutzer, SEPA und Online-Bestellung. |
