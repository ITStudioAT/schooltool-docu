# Online-Bestellung

import ZoomImage from '@site/src/components/ZoomImage';

Unter **Online** wird festgelegt, wann Menüpläne sichtbar und bestellbar sind.

<ZoomImage src={require('../../images/admin-einstellungen-online-bestellung.png').default} alt="Online-Bestellung in den Restaurant-Einstellungen" />

Folgende Einstellungen können durchgeführt werden:

- **Bestellstart**: sofort nach Verfügbarkeit oder an einem festen Tag mit Uhrzeit.
- **Bestellende**: fixer Tag mit Uhrzeit.
- **Sichtbarkeitsstart**: sobald verfügbar, sobald bestellbar oder an einem festen Tag mit Uhrzeit.
- **Sichtbarkeitsende**: am Ende des Menüplans oder am Ende der Woche.

Die Online-Einstellungen enthalten eine Vorschau, mit der die Auswirkung der gewählten Zeiten auf Menüpläne geprüft werden kann.
