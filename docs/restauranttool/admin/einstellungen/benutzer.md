# Benutzer

Im Bereich **Benutzer** können Restaurant-Benutzer gesucht und verwaltet werden.

Folgende Funktionen stehen zur Verfügung:

- Suche nach Name, E-Mail-Adresse oder Klasse.
- Filter auf Benutzer, die noch bestätigt werden müssen.
- Filter auf Benutzer ohne SEPA.
- Restaurant-Benutzer bestätigen.
- Offene Restaurant-Kandidaten löschen.
- SEPA-Status einzelner Benutzer setzen.
- SEPA-Status einzelner Benutzer entfernen.

Beim Entfernen eines SEPA-Status werden auch die gespeicherten SEPA-Lastschriftmandate für diesen Benutzer gelöscht.
