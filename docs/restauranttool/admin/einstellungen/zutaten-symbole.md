# Zutaten-Symbole

import ZoomImage from '@site/src/components/ZoomImage';

Unter **Zutaten-Symbole** werden SVG-Symbole verwaltet. Diese Symbole können später Speisen zugeordnet werden, zum Beispiel für Allergene, Zutaten oder besondere Hinweise.

<ZoomImage src={require('../../images/admin-einstellungen-zutaten-symbole.png').default} alt="Zutaten-Symbole in den Restaurant-Einstellungen" />

Folgende Aktionen sind möglich:

- Neues Symbol anlegen.
- Titel eines Symbols bearbeiten.
- SVG-Datei hochladen.
- Bestehendes Bild entfernen.
- Symbol löschen.
- Symbole aus einem vorbereiteten Verzeichnis übernehmen.

In der Übersicht wird je Symbol angezeigt, wie viele Speisen das Symbol verwenden.
