# Speisezeiten

import ZoomImage from '@site/src/components/ZoomImage';

Unter **Speisezeiten** werden die verfügbaren Uhrzeiten für das Essen gepflegt.

<ZoomImage src={require('../../images/admin-einstellungen-speisezeiten.png').default} alt="Speisezeiten in den Restaurant-Einstellungen" />

Neue Zeiten werden im Format `HH:MM` erfasst, zum Beispiel `11:30` oder `12:45`.

Folgende Aktionen sind möglich:

- Neue Speisezeit anlegen.
- Bestehende Speisezeit bearbeiten.
- Speisezeit löschen.
