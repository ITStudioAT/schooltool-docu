# SEPA

Unter **SEPA** werden die Vorgaben für das Lastschriftmandat hinterlegt.

Folgende Einstellungen können durchgeführt werden:

- Online-SEPA für Benutzer aktivieren oder deaktivieren.
- Zahlungsempfänger als formatierten Text eintragen.
- SEPA-Ermächtigungstext bearbeiten.
- Vorschau des SEPA-Formulars öffnen.

Die Vorschau zeigt das Formular mit den aktuell hinterlegten Angaben.
