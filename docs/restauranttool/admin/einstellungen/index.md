# Einstellungen

Im Bereich **Einstellungen** werden grundlegende Vorgaben für das Restauranttool verwaltet. Die Einstellungen sind in mehrere Register aufgeteilt.

## Übersicht

| Bereich | Was kann eingestellt werden? |
| --- | --- |
| [Allgemein](./allgemein) | Service-E-Mail-Adresse, Bestätigung neuer Benutzer und Einleitungstext für die Restaurant-Benutzerinformation. |
| [Kategorien](./kategorien) | Speisekategorien anlegen, bearbeiten, sortieren und löschen. |
| [Zutaten-Symbole](./zutaten-symbole) | Symbole für Zutaten oder Hinweise anlegen, SVG-Dateien hochladen, bestehende Symbole bearbeiten oder löschen und Symbole aus einem Verzeichnis übernehmen. |
| [Freie Tage](./freie-tage) | Tage oder Datumsbereiche markieren, an denen kein Restaurantbetrieb bzw. keine Bestellung vorgesehen ist. Die Ansicht kann jahresweise gewechselt werden. |
| [Speisezeiten](./speisezeiten) | Essenszeiten im Format `HH:MM` anlegen, bearbeiten und löschen. |
| [Benutzer](./benutzer) | Restaurant-Benutzer suchen, filtern, bestätigen, offene Kandidaten löschen und SEPA-Status einzelner Benutzer setzen oder entfernen. |
| [SEPA](./sepa) | Online-SEPA aktivieren oder deaktivieren, Zahlungsempfänger und SEPA-Ermächtigungstext bearbeiten sowie eine Vorschau des SEPA-Formulars öffnen. |
| [Online-Bestellung](./online-bestellung) | Sichtbarkeit und Bestellbarkeit von Menüplänen steuern, zum Beispiel Bestellstart, Bestellende, Sichtbarkeitsstart und Sichtbarkeitsende. |
