# Freie Tage

import ZoomImage from '@site/src/components/ZoomImage';

Unter **Freie Tage** werden einzelne Tage oder ganze Zeiträume vorgemerkt und anschließend gespeichert. Dadurch kann festgelegt werden, wann keine regulären Restauranttage stattfinden.

<ZoomImage src={require('../../images/admin-einstellungen-freie-tage.png').default} alt="Freie Tage in den Restaurant-Einstellungen" />

Die Jahresansicht kann zwischen Vorjahr, aktuellem Jahr und nächstem Jahr gewechselt werden.

Folgende Aktionen sind möglich:

- Einzelne Tage durch Anklicken vormerken.
- Einen Datumsbereich auswählen und vormerken.
- Vorgemerkte Änderungen speichern.
- Ungespeicherte Änderungen verwerfen.

Änderungen werden erst übernommen, wenn sie gespeichert werden.
