# Kategorien

import ZoomImage from '@site/src/components/ZoomImage';

Mit **Kategorien** werden die Speisen gruppiert, z. B. Vorspeise, Hauptspeise oder Nachspeise.

<ZoomImage src={require('../../images/admin-einstellungen-kategorien.png').default} alt="Kategorien in den Restaurant-Einstellungen" />

Pro Kategorie können folgende Angaben gepflegt werden:

- **Kategoriename**: Bezeichnung der Kategorie.
- **Reihenfolge**: Sortierung der Kategorie innerhalb der Liste.

Kategorien können angelegt, bearbeitet und gelöscht werden. In der Übersicht wird zusätzlich angezeigt, wie viele Speisen der jeweiligen Kategorie zugeordnet sind.
