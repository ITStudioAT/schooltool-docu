# Allgemein

import ZoomImage from '@site/src/components/ZoomImage';

Unter **Allgemein** werden schulweite Restaurant-Angaben gepflegt:

<ZoomImage src={require('../../images/admin-einstellungen-allgemein.png').default} alt="Allgemeine Restaurant-Einstellungen im Admin-Bereich" />

- **Service-E-Mail-Adresse**: Kontaktadresse für Restaurant-Anfragen.
- **Neue Benutzer müssen bestätigt werden**: legt fest, ob neue Restaurant-Benutzer nach der Registrierung freigegeben werden müssen.
- **E-Mail-Adresse für Bestätigung**: Adresse, an die Bestätigungsinformationen gesendet werden, wenn die Benutzerbestätigung aktiv ist.

:::tip Empfehlung

Die Einstellung **Neue Benutzer müssen bestätigt werden** sollte auf **Ja** gesetzt sein. Dadurch können sich keine fremden, nicht autorisierten Benutzer selbstständig für das Restauranttool freischalten.

:::

- **Text für die erste Seite der Restaurant-Benutzerinformation**: frei formatierbarer Einleitungstext für die Benutzerinformation.

<ZoomImage src={require('../../images/restaurant-benutzerinformation-startseite.png').default} alt="Restaurant-Startseite mit Benutzerinformation aus Besuchersicht" />
