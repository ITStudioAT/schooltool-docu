# Überblick

import ZoomImage from '@site/src/components/ZoomImage';

Der **Überblick** ist die Startseite des Restaurant-Bereichs. Er zeigt wichtige Kennzahlen und bietet direkte Einstiege in die wichtigsten Arbeitsbereiche.

<ZoomImage src={require('../../images/admin-restaurant-ueberblick.png').default} alt="Überblick im Restaurant-Adminbereich" />

Angezeigt werden unter anderem:

- Anzahl der angelegten Speisen.
- Anzahl der angelegten Menüs.
- Anzahl der Restaurant-Benutzer.
- Anzahl der Benutzer, die noch bestätigt werden müssen.
- Anzahl der gebuchten Menüs.

Über die Schaltflächen kann direkt zu Speisen, Menüs, Benutzern, offenen Benutzerbestätigungen oder Menüplänen gewechselt werden.
