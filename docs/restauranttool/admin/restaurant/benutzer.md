# Benutzer

Unter **Benutzer** werden alle Restaurant-Benutzer der ausgewählten Schule verwaltet.

Die Benutzerliste kann nach Name, E-Mail-Adresse oder Klasse durchsucht werden. Zusätzlich stehen Filter für offene Bestätigungen und fehlende SEPA-Bestätigung zur Verfügung.

Bei Benutzern werden unter anderem folgende Informationen angezeigt:

- Name und E-Mail-Adresse.
- SEPA-Status.
- E-Mail-Bestätigung.
- allgemeiner Bestätigungsstatus.
- Restaurant-Bestätigungsstatus.
- Herkunft des Benutzers.
- Klasse, Telefonnummer und zugeordnete Kinder, sofern vorhanden.

Folgende Aktionen sind möglich:

- Restaurant-Benutzer bestätigen.
- Ausstehende Kandidaten löschen.
- SEPA manuell bestätigen.
- SEPA entfernen.
- Benutzerliste aktualisieren.
