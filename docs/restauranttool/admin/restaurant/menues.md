# Menüs

import ZoomImage from '@site/src/components/ZoomImage';

Unter **Menüs** werden mehrere Speisen zu einer Menüfolge zusammengestellt. Ein Menü kann aus einem oder mehreren Gängen bestehen.

<ZoomImage src={require('../../images/admin-restaurant-menues.png').default} alt="Menüs im Restaurant-Adminbereich" />

Beim Anlegen oder Bearbeiten eines Menüs werden zuerst Kategorie und Speise ausgewählt. Jeder hinzugefügte Eintrag wird als Gang in die Menüfolge übernommen. Die Reihenfolge der Gänge kann anschließend angepasst werden.

Folgende Aktionen sind möglich:

- Neues Menü anlegen.
- Bestehendes Menü bearbeiten.
- Menü löschen.
- Menü nach Titel, enthaltenen Speisen oder Kategorien suchen.
- Zwischen Detailansicht, Bildansicht und Kompaktansicht wechseln.
- Preis für ein Menü pflegen.

Menüs werden später in Menüplänen verwendet.
