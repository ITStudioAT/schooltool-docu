# Speisen

import ZoomImage from '@site/src/components/ZoomImage';

Unter **Speisen** werden einzelne Gerichte gepflegt. Diese Speisen bilden später die Bausteine für Menüs und Menüpläne.

<ZoomImage src={require('../../images/admin-restaurant-speisen.png').default} alt="Speisen im Restaurant-Adminbereich" />

Folgende Angaben können verwaltet werden:

<ZoomImage src={require('../../images/admin-restaurant-speisen-formular.png').default} alt="Speise anlegen oder bearbeiten im Restaurant-Adminbereich" framed />

- **Titel** der Speise.
- **Kategorie**, zum Beispiel Vorspeise, Hauptspeise oder Nachspeise.
- **Beschreibung** der Speise.
- **Speisenbild** als Bilddatei.
- **Allergene**.
- **Zutaten-Symbole** bzw. Hinweise.
- **Preis**.

Speisen können gesucht, nach Kategorie gefiltert, in einer Detail- oder Kompaktansicht angezeigt, neu angelegt, bearbeitet und gelöscht werden. Die Anzahl der Speisen pro Seite kann angepasst werden.
