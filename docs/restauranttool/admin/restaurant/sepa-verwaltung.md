# SEPA Verwaltung

Unter **SEPA Verwaltung** werden Kunden angezeigt, die ein SEPA-Lastschriftmandat online bestätigt haben.

Für jeden Eintrag werden Name, E-Mail-Adresse, Klasse, Zeitpunkt der Online-Bestätigung, Einstiegspunkt und eine eindeutige Identifikation angezeigt.

Folgende Aktionen sind möglich:

- Online bestätigte SEPA-Mandate seitenweise anzeigen.
- SEPA-Mandat eines Benutzers als PDF drucken.

Diese Ansicht dient vor allem zur Kontrolle und Ablage online bestätigter Lastschriftmandate.
