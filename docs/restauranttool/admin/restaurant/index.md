# Restaurant

Der Bereich **Restaurant** ist die zentrale Arbeitsoberfläche für die laufende Restaurantverwaltung. Hier werden Speisen und Menüs gepflegt, Menüpläne erstellt, Bestellungen ausgewertet, Benutzer verwaltet und SEPA-Mandate geprüft.

Die Seite ist im Admin-Bereich unter `http://localhost:8000/admin/restaurant` erreichbar.

## Übersicht

| Bereich | Beschreibung |
| --- | --- |
| [Überblick](./ueberblick) | Startseite mit Kennzahlen und Schnellzugriffen auf Speisen, Menüs, Benutzer, offene Bestätigungen und Menüpläne. |
| [Speisen](./speisen) | Einzelne Speisen mit Kategorie, Beschreibung, Bild, Allergenen, Zutaten-Symbolen und Preis anlegen und bearbeiten. |
| [Menüs](./menues) | Menüs aus mehreren Speisen bzw. Gängen zusammenstellen, Preise pflegen und Menüs in verschiedenen Ansichten verwalten. |
| [Menüpläne](./menueplaene) | Menüpläne über eine Kalenderansicht erstellen, bearbeiten, drucken, auf- oder zusperren. |
| [Auswertungen](./auswertungen) | Bestelllisten, Menüplansummen und Abrechnungen für ausgewählte Zeiträume drucken. |
| [Benutzer](./benutzer) | Restaurant-Benutzer suchen, filtern, bestätigen, löschen und SEPA-Status verwalten. |
| [SEPA Verwaltung](./sepa-verwaltung) | Online bestätigte SEPA-Lastschriftmandate anzeigen und als PDF drucken. |
