# Auswertungen

import ZoomImage from '@site/src/components/ZoomImage';

Unter **Auswertungen** werden druckbare Listen und Abrechnungen für das Restaurant erstellt.

<ZoomImage src={require('../../images/admin-restaurant-auswertungen.png').default} alt="Auswertungen im Restaurant-Adminbereich" />

## Menüsummen drucken

Im Bereich **Menüsummen drucken** wird ein Menüplan ausgewählt. Dazu werden aktuelle, vergangene und zukünftige Menüpläne angezeigt. Für den gewählten Plan kann eine Bestellliste gedruckt werden.

<ZoomImage src={require('../../images/admin-restaurant-auswertungen-bestellliste.png').default} alt="Bestellliste in den Restaurant-Auswertungen" framed />

Die Anzeige enthält Hinweise zur Sichtbarkeit, Bestellbarkeit und Anzahl der Buchungen.

## Abrechnung drucken

Im Bereich **Abrechnung drucken** werden abrechenbare Kalenderwochen ausgewählt. Für den gewählten Zeitraum kann eine Abrechnung angesehen und anschließend erstellt bzw. gedruckt werden.

<ZoomImage src={require('../../images/admin-restaurant-auswertungen-abrechnung.png').default} alt="Abrechnung in den Restaurant-Auswertungen" framed />

Bereits erstellte Abrechnungen werden in einer Liste angezeigt und können erneut geöffnet werden.
