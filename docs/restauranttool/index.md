# Restauranttool

Mit dem _Restauranttool_ können Mittagsmenüs von den Kunden im Vorhinein gebucht werden.

import ZoomImage from '@site/src/components/ZoomImage';

## Übersicht

Es werden in einer übersichtlichen Tabelle alle Menüs angezeigt. Der Kunde loggt sich ein und kann durch Anklicken seine Wunschmenüs bestellen. Natürlich sind Änderungen der Bestellung bis zum Ende der Bestellfrist jederzeit möglich.

## Erste Schritte

Die Verwaltung des _Restauranttools_ ist sehr einfach gehalten:

- Legen Sie die Speisen an (Vor-, Haupt-, Nachspeisen)
- Ordnen Sie den Menüs die Speisen und den Preis zu
- Legen Sie für jede Woche fest, wann es welche Menüs gibt und in welchem Zeitraum der Kunde bestellen kann

## Funktionsumfang

Sie erhalten einen Zugang zur Restaurant-Verwaltung, wo sie Speisen, Menüs und Menüwochen verwalten können.
Die Kunden können (auf Wunsch mit Kunden-Freigabe) ab sofort bestellen.
Sie erhalten eine detaillierte Bestellliste sowohl für die benötigten Menümengen als auch für die Ausgabe der Menüs.

Sie können jederzeit eine Abrechnungs-Liste der Kunden-Konsumationen erstellen.

:::info Hinweis
Die SEPA-Abbuchungsermächtigungen können ebenfalls völlig automatisiert online erstellt bzw. verwaltet werden.
:::
